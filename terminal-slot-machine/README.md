# 🎰 Terminal Slot Machine

A command-line slot machine game built in Python. Users can deposit money, bet across multiple lines, and spin the machine to test their luck.

## Features
- Deposit money and place bets on up to 3 lines
- Winnings based on matching symbols
- Customizable symbol probabilities and values
- Tracks user balance throughout the session

## How to Run

```bash
python main.py
