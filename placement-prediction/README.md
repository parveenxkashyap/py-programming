# Placement Prediction Web App

A simple end-to-end machine learning project that predicts whether a student will get placed based on their **IQ** and **CGPA**.  
The project covers the complete ML workflow — from data preprocessing and model training to deployment using **Streamlit**.

---

## 🚀 Project Overview
This project uses a **Logistic Regression** model to classify student placement outcomes.  
A trained model is saved and then loaded into a Streamlit web application where users can enter details and get instant predictions.

---

## 📌 Features
- Data preprocessing and exploratory data analysis (EDA)
- Feature scaling using StandardScaler
- Logistic Regression model training
- Model evaluation using accuracy score
- Decision boundary visualization
- Model persistence using pickle
- Interactive web app built with Streamlit

---

## 🧠 Machine Learning Pipeline
1. Load dataset
2. Clean and preprocess data
3. Perform EDA
4. Select features and target
5. Train-test split
6. Feature scaling
7. Train Logistic Regression model
8. Evaluate model performance
9. Save trained model
10. Deploy using Streamlit
